

# Technical Specification: Neuro-Symbolic Semantic Role Labeling (SRL) & Ambiguity Resolution Engine

This document provides the architectural specification, formal algorithmic formulation, and end-to-end implementation blueprint for the Neuro-Symbolic Semantic Role Labeling engine. It is structured as an authoritative reference specification for use by automated coding agents (such as Claude Code) and developers to implement the entire system without architectural ambiguity.

---

## 1. System Overview & Core Technical Thesis

### 1.1 The Core Problem

Standard deep learning architectures (Transformers, BiLSTMs) and Large Language Models (LLMs) act as soft statistical sequence estimators. When parsing morphologically rich, syntactically flexible, or scrambled Indian languages (e.g., Hindi), pure neural models frequently fail in three predictable ways:

1. **Surface Clitic Heuristic Trapping:** Associating the ergonomic case marker *ne* (ने) strictly with an intentional agent (`ARG0`), even when attached to inanimate instruments in non-standard syntax or passive constructions.
2. **Structural Attachment & Scope Ambiguity:** Incorrectly binding postpositional phrases (e.g., instrumental *se* [से] or locative *mein* [में]) to the nearest nominal head instead of the verbal predicate (or vice versa).
3. **Semantic Incoherence under Free Word Order:** Because sentence arguments can be freely scrambled without changing core meaning, models trained purely on positional associations hallucinate argument spans or produce structurally impossible frames (e.g., assigning multiple conflicting `ARG0` roles to a single monovalent predicate).

### 1.2 The Neuro-Symbolic Solution

The system resolves these failure modes by decoupling feature extraction from structural validation:

* **The Neural Component:** A deep Bidirectional Long Short-Term Memory (BiLSTM) network over pretrained multilingual token representations extracts continuous contextual features, flags predicate candidates, and computes soft emission potentials across token spans.
* **The Symbolic Component:** An ontological knowledge graph—**IndoWordNet** (IIT Bombay CFILT)—acts as a deterministic semantic filter. It supplies synset hierarchies, hypernymy paths, and semantic selectional restrictions for candidate predicates.
* **The Interface (Constrained Viterbi-CRF):** Instead of standard unconstrained sequence decoding, inference is cast as a global optimization problem over a Linear-Chain Conditional Random Field (CRF) whose emission matrix is masked at runtime by an **Ontology Masking Tensor** derived from IndoWordNet. If a candidate assignment violates selectional restrictions (e.g., assigning an inanimate entity as the volitional agent of an intentional action), its emission score is penalized toward $-\infty$, forcing the decoder to find the globally optimal, linguistically valid parse.

## 2. Mathematical Formulation & Architecture Components

### 2.1 Input Representation & Morphological Scaffolding

Let an input sentence be an ordered sequence of $N$ tokens:


$$X = (x_1, x_2, \dots, x_N)$$

For each token $x_i$, three parallel representations are computed and concatenated into a composite input vector $e_i \in \mathbb{R}^{d_{\text{total}}}$:

1. **Dense Contextual Representation ($w_i \in \mathbb{R}^{768}$):** Extracted from the frozen or fine-tuned penultimate layer of an Indic encoder (e.g., `ai4bharat/indic-bert` or `google/muril-base-cased`).
2. **Morphological Clitic Feature Vector ($m_i \in \mathbb{R}^{d_{\text{morph}}}$):** Dense embeddings of explicit morphological tags derived from finite-state or statistical analysis:
* Case postposition markers (e.g., *ne*, *ko*, *se*, *ka/ki/ke*, *mein*, *par*, or $\emptyset$ for direct case).
* Voice/aspect markers (active, passive, causative).


3. **Predicate Indicator Embedding ($p_i \in \mathbb{R}^{d_{\text{pred}}}$):** A binary or learned flag indicating whether token $x_i$ is the target predicate being evaluated in the current forward pass:

$$e_i = [w_i \,;\, m_i \,;\, p_i]$$



### 2.2 Contextual Sequence Encoder

The composite vectors $(e_1, \dots, e_N)$ are fed into a 3-layer Bidirectional LSTM:


$$\overrightarrow{h}_i = \text{LSTM}_{\text{fwd}}(e_i, \overrightarrow{h}_{i-1})$$

$$\overleftarrow{h}_i = \text{LSTM}_{\text{bwd}}(e_i, \overleftarrow{h}_{i+1})$$

$$h_i = [\overrightarrow{h}_i \,;\, \overleftarrow{h}_i] \in \mathbb{R}^{2 \cdot d_{\text{hidden}}}$$

$h_i$ encodes unbounded bidirectional context, local syntactic agreement, and long-range dependencies across scrambled constituents.

### 2.3 Joint Predicate Word Sense Disambiguation (WSD)

For an identified predicate token at index $p$ with hidden state $h_p$:

1. Query IndoWordNet for the set of candidate synsets associated with the predicate lemma:

$$S(x_p) = \{s_1, s_2, \dots, s_K\}$$


2. For each synset $s_k$, construct a symbolic gloss-hypernym representation vector $g_k \in \mathbb{R}^{d_{\text{gloss}}}$ using a sentence-encoder over the synset's Hindi gloss text, example sentences, and hypernym path tokens.
3. Compute normalized sense probability distribution over candidate synsets via dot-product attention:

$$\alpha_k = \frac{\exp(h_p^T W_{\text{sense}} g_k)}{\sum_{j=1}^K \exp(h_p^T W_{\text{sense}} g_j)}$$


4. The winning predicate sense is:

$$\hat{s}_p = \arg\max_{k} (\alpha_k)$$



### 2.4 Argument Role Scorer & The Ontology Masking Matrix

Let $R$ be the set of valid semantic role labels in BIO format (e.g., `B-ARG0`, `I-ARG0`, `B-ARG1`, `I-ARG1`, `B-ARGM-LOC`, `O`). The neural scorer computes raw emission potentials for each token $i$ and role $r \in R$:


$$\psi_{\text{neural}}(i, r) = W_{\text{role}} \cdot \text{GELU}(W_{\text{arg}} h_i + W_{\text{pred}} h_p + b_{\text{arg}})$$

To enforce symbolic constraints, a dynamic **Ontology Masking Matrix** $M \in \mathbb{R}^{N \times \vert{}R\vert{}}$ is computed at runtime by matching candidate token synsets against the selectional restrictions of the active predicate sense $\hat{s}_p$:


$$M(i, r) = \begin{cases} 0 & \text{if span containing token } x_i \text{ satisfies ontological axioms of role } r \\ -\infty & \text{if span violates selectional restrictions or structural invariants} \end{cases}$$

**Constraint Rules Encoded in $M$:**

1. **Animacy Restriction:** If $\hat{s}_p$ requires an intentional/agentive subject, and the entity head of token $x_i$ traces its IndoWordNet hypernym tree to `[निर्जीव / Inanimate]` or `[अमूर्त / Abstract]`, then:

$$M(i, \text{B-ARG0}) = -\infty, \quad M(i, \text{I-ARG0}) = -\infty$$


2. **Spatial/Temporal Conformance:** If token $x_i$ lacks locative postpositions or its synset cannot be subsumed under `[स्थान / Location]`, then:

$$M(i, \text{B-ARGM-LOC}) = -\infty$$


3. **Uniqueness Constraints:** A monovalent/bivalent verbal frame cannot admit more than one unique instance of core arguments (`ARG0`, `ARG1`).

### 2.5 Constrained Global Decoding (Viterbi-CRF)

The final emission score for token $i$ taking label $y_i \in R$ is:


$$\phi(i, y_i) = \psi_{\text{neural}}(i, y_i) + M(i, y_i)$$

The score of an entire sequence of labels $\mathbf{y} = (y_1, y_2, \dots, y_N)$ given sentence $X$ and predicate index $p$ is:


$$S(X, p, \mathbf{y}) = \sum_{i=1}^N \phi(i, y_i) + \sum_{i=1}^{N-1} A_{y_i, y_{i+1}}$$


where $A \in \mathbb{R}^{\vert{}R\vert{} \times \vert{}R\vert{}}$ is the learnable transition matrix modeling label-to-label dependencies (e.g., forbidding `I-ARG0` directly following `B-ARG1`).

During training, the objective minimizes the negative log-likelihood of the gold sequence $\mathbf{y}^*$ marginalized across all possible paths via the forward-backward algorithm, plus an auxiliary cross-entropy loss over predicate senses:


$$\mathcal{L}_{\text{total}} = -\log \left( \frac{\exp(S(X, p, \mathbf{y}^*))}{\sum_{\mathbf{y}' \in \mathcal{Y}} \exp(S(X, p, \mathbf{y}'))} \right) + \lambda \mathcal{L}_{\text{WSD}}(\hat{s}_p, s_p^*)$$

During inference, decoding searches for the optimal sequence $\mathbf{y}_{\text{best}} = \arg\max_{\mathbf{y}} S(X, p, \mathbf{y})$ using the dynamic programming Viterbi algorithm over the ontology-masked emission matrix.

## 5. Step-by-Step Implementation Blueprint

### Phase 1: Environment Setup, Tooling & Lexical Ontology Initialization

1. **Runtime & Base Tooling:** Python 3.10+, PyTorch 2.x, Hugging Face `transformers`, `seqeval`, `pydantic`, `fastapi`, `onnx`, `onnxruntime`.
2. **Lexical Resource Installation:**
* Integrate `pyiwn` (Python IndoWordNet interface) developed by CFILT, IIT Bombay.
* Write an initialization script (`src/ontology/indowordnet_client.py`) that loads the Hindi synset database, downloads the language dump, and establishes in-memory lookup indices for fast querying.


3. **Gloss Embedding Cache:**
* Pre-compute dense representations for all IndoWordNet verbal and nominal synset glosses using a multilingual sentence transformer (`sentence-transformers/paraphrase-multilingual-mpnet-base-v2`).
* Store these gloss vectors in a memory-mapped binary array or SQLite cache (`data/indowordnet_cache/`) to eliminate repetitive embedding overhead during training and inference.



### Phase 2: Data Preprocessing & Alignment Engine

1. **Corpus Acquisition:**
* Download the **Hindi Dependency Treebank (HDTB)** and the **Universal Propositions (UP_Hindi)** dataset in CoNLL-U format.


2. **Label Alignment (Paninian Karaka to PropBank SRL):**
* Implement `src/data_pipeline/hdtb_parser.py` to convert dependency-based Karaka relations into span-level Semantic Role Labels:
* `k1` (Karta - Agent) $\rightarrow$ `ARG0`
* `k2` (Karma - Patient/Theme) $\rightarrow$ `ARG1`
* `k3` (Karana - Instrument) $\rightarrow$ `ARG2` or `ARGM-INS`
* `k4` (Sampradana - Beneficiary/Recipient) $\rightarrow$ `ARGM-GOL`
* `k5` (Apadaana - Source) $\rightarrow$ `ARGM-SRC`
* `k7p` (Sthanadhikarana - Place/Locus) $\rightarrow$ `ARGM-LOC`
* `k7t` (Kaladhikarana - Time/Temporal) $\rightarrow$ `ARGM-TMP`




3. **BIO Tag Formulation:**
* Convert span boundaries into explicit token tags: `B-ARG0`, `I-ARG0`, `B-ARG1`, `I-ARG1`, `B-ARGM-LOC`, `I-ARGM-LOC`, etc., with `O` representing non-argument tokens.


4. **Morphological Clitic Feature Extraction:**
* Implement `src/data_pipeline/morphology_extractor.py` to detect grammatical markers. Parse postpositions immediately following nouns/pronouns:
* Agentive: *ne* (ने)
* Accusative/Dative: *ko* (को)
* Instrumental/Ablative: *se* (से)
* Genitive: *ka*, *ke*, *ki* (का, के, की)
* Locative: *mein*, *par*, *tak* (में, पर, तक)


* Map these markers into integer indices for embedding lookup.



### Phase 3: Dual-Head Neural Architecture Construction

1. **Backbone Encoder (`src/models/encoder.py`):**
* Instantiate an Indic transformer backbone (`ai4bharat/indic-bert`). Extract token embeddings.
* Concatenate transformer output with the learned morphological feature embeddings.
* Pass the unified representations through a stacked 3-layer BiLSTM ($d_{\text{hidden}} = 512$, dropout = $0.33$) to capture linear syntactic structure and long-range modifier bindings.


2. **Predicate Sense Disambiguation Head (`src/models/wsd_head.py`):**
* Extract the hidden vector $h_p$ at the predicate index $p$.
* Project candidate IndoWordNet gloss embeddings into the model's latent dimension via a projection matrix $W_{\text{sense}}$.
* Compute dot-product attention over candidate synset embeddings to output a probability distribution over valid senses.


3. **Role Scorer Head (`src/models/role_scorer.py`):**
* For every token $i \in \{1, \dots, N\}$, form a pairwise representation with the target predicate $p$: $[h_i \,;\, h_p \,;\, (h_i - h_p) \,;\, h_i \odot h_p]$.
* Pass this through a 2-layer MLP with GELU activations to produce unconstrained emission potentials $\psi_{\text{neural}} \in \mathbb{R}^{N \times \vert{}R\vert{}}$.



### Phase 4: Symbolic Knowledge Integration & Masking Engine

1. **Ontological Graph Traversal (`src/ontology/hypernym_engine.py`):**
* Implement an ontology query engine that, given a token lemma, retrieves its synset and navigates parent nodes along the hypernym tree.
* Define Boolean predicates:
* `is_animate(token)`: Checks if the hypernym path terminates in or intersects nodes `[चेतन / Animate]`, `[जीव / Living Being]`, or `[मानव / Human]`.
* `is_location(token)`: Checks for subsumption under `[स्थान / Location]` or `[भूगोलीय क्षेत्र / Geographical Area]`.
* `is_time(token)`: Checks for subsumption under `[समय / Time]` or `[काल / Temporal Unit]`.
* `is_instrument(token)`: Checks for `[उपकरण / Tool/Instrument]` or `[साधन / Means]`.




2. **Dynamic Mask Generator (`src/ontology/mask_generator.py`):**
* For the predicted or gold predicate sense, fetch frame constraints.
* Generate matrix $M \in \mathbb{R}^{N \times \vert{}R\vert{}}$ initialized with zeros.
* Iterate over each token $i$:
* If evaluating role `B-ARG0` or `I-ARG0`, and `is_animate(token_i)` is False, and the predicate is an intentional transitive verb (e.g., *dekhna* [to see], *sochna* [to think], *likhna* [to write]), set $M(i, \text{ARG0}) = -10000.0$.
* If evaluating role `ARGM-LOC` and both postposition is not locative and `is_location(token_i)` is False, set $M(i, \text{ARGM-LOC}) = -10000.0$.
* If evaluating role `ARGM-TMP` and token is not temporal, set $M(i, \text{ARGM-TMP}) = -10000.0$.





### Phase 5: Constrained Decoding & Multi-Task Training Pipeline

1. **Custom Masked CRF Layer (`src/models/crf_layer.py`):**
* Implement a Linear-Chain CRF in PyTorch that natively accepts the additive masking matrix $M$:

$$\Phi = \Psi_{\text{neural}} + M$$


* In the forward pass during training, compute the partition function $Z(X)$ using the forward algorithm in log-space over $\Phi$.
* Compute gold path score $S(X, \mathbf{y}^*)$ and formulate negative log-likelihood: $\mathcal{L}_{\text{CRF}} = \log Z(X) - S(X, \mathbf{y}^*)$.


2. **Constrained Viterbi Decoding (`src/inference/viterbi_decoder.py`):**
* During inference, execute dynamic programming using backpointers over masked emissions $\Phi$ and learned transition parameters $A$.
* Add global post-processing assertions: enforce that at most one continuous span receives `ARG0` and at most one span receives `ARG1` per predicate frame.


3. **Training Execution Loop (`scripts/train.py`):**
* Optimizer: AdamW with decoupled weight decay ($\text{lr} = 2 \times 10^{-5}$ for IndicBERT layers, $\text{lr} = 1 \times 10^{-3}$ for BiLSTM, MLP, and CRF parameters).
* Learning rate schedule: Linear warmup for the first 10% of total training steps, followed by cosine decay.
* Multi-Task Objective:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CRF}} + \lambda \mathcal{L}_{\text{WSD}}$$



where $\lambda = 0.4$.
* Monitor span-level Macro-F1 via `seqeval` on the validation split after every epoch; perform early stopping with a patience of 5 epochs.



### Phase 6: Optimization, ONNX Export & Production Serving

1. **Graph Serialization & Quantization (`src/inference/onnx_exporter.py`):**
* Trace the neural components (IndicBERT feature extractor + BiLSTM + Role Scorer MLP) into an ONNX graph.
* Note: Keep the symbolic masking matrix generation and Viterbi search in native Python/NumPy or C++ extensions, as dynamic graph search with arbitrary graph lookups is more maintainable outside raw computational graphs.
* Apply dynamic 8-bit quantization (`onnxruntime.quantization.quantize_dynamic`) targeting `QInt8` for linear and recurrent matrix multiplications.


2. **High-Throughput API Engine (`api/main.py`):**
* Implement a production-grade FastAPI application with lifespan context management to load the ONNX inference session and IndoWordNet trie structures on startup.
* Create an endpoint: `POST /api/v1/parse_frame`:
* Accepts: `{"text": "...", "target_predicate": "..."}` (optional predicate index; auto-detects verbs if omitted).
* Returns: A structured JSON response detailing identified predicate, synset definition, and a list of arguments containing token spans, text, Karaka mappings, and PropBank roles.




3. **Benchmarking & Validation (`scripts/benchmark_latency.py`):**
* Measure p50, p95, and p99 inference latencies on CPU across 1,000 synthetic sentences.
* Verify memory footprint reduction and confirm zero drift in Macro-F1 between FP32 PyTorch and INT8 ONNX models.

## 6. Edge-Case Resolution & Verification Matrix

Below are concrete test sentences demonstrating how this neuro-symbolic framework systematically corrects errors that cause standard neural models to fail.

### Test Case 1: Animacy Inversion with Ergonomic Postposition (*Instrument as Surface Subject*)

* **Input Sentence:** *चाबी ने ताला खोला* (*The key opened the lock*).
* **Pure Neural Failure Mode:** The token *चाबी* (key) is suffixed with the postposition *ne* (ने). Pure sequence taggers heavily weigh the surface statistic $P(\text{ARG0} \mid \text{"ने"}) \approx 0.92$, assigning *चाबी* as `ARG0` (Volitional Agent).
* **Neuro-Symbolic Disambiguation:**
1. Predicate *खोला* (open) resolves to sense `खोलना.v.01` (action requiring an intentional agent).
2. IndoWordNet hypernym check for *चाबी*: `चाबी` $\rightarrow$ `कुंजी` $\rightarrow$ `उपकरण` (Tool) $\rightarrow$ `[निर्जीव / Inanimate]`.
3. Mask generator flags violation: $M(\text{चाबी}, \text{ARG0}) = -\infty$.
4. The Viterbi decoder is forced to assign *चाबी* to `ARG2` / `ARGM-INS` (Instrument), maintaining semantic truth.



### Test Case 2: Free-Word-Order Scrambling (OSV Word Order)

* **Input Sentence:** *सेब को बच्चे ने खाया* (*The apple, the child ate*).
* **Pure Neural Failure Mode:** Position-dependent models frequently classify the first noun phrase as `ARG0` due to canonical SOV word order bias in training data, labeling *सेब* (apple) as the eater.
* **Neuro-Symbolic Disambiguation:**
1. Postposition extractor identifies *ko* (accusative/patient marker) on *सेब* and *ne* (agent marker) on *बच्चे*.
2. IndoWordNet confirms *बच्चा* (child) $\rightarrow$ `[मानव / Human]` $\rightarrow$ `[चेतन / Animate]`, satisfying `ARG0`.
3. IndoWordNet confirms *सेब* (apple) $\rightarrow$ `[खाद्य पदार्थ / Food]` $\rightarrow$ `[मूर्त वस्तु / Physical Object]`, satisfying `ARG1` selectional restriction of *खाना* (eat).
4. Global sequence probability assigns: *सेब को* $\rightarrow$ `ARG1`, *बच्चे ने* $\rightarrow$ `ARG0`, regardless of constituent position.



### Test Case 3: Attachment Ambiguity in Complex Nominal Modification

* **Input Sentence:** *पुलिस ने दूरबीन से चोर को देखा* (*The police saw the thief with a telescope*).
* **Structural Ambiguity:** Does *दूरबीन से* (with a telescope) attach to the verb *देखा* (instrument of seeing) or to the noun *चोर* (the thief possessing a telescope)?
* **Neuro-Symbolic Disambiguation:**
1. IndoWordNet verbal frame for *देखना* (sense: visual perception) explicitly admits an optical instrument role (`ARGM-INS` via instrumental case *se*).
2. The pairwise edge scorer checks affinity: $\text{Affinity}(\text{दूरबीन}, \text{देखना}) \gg \text{Affinity}(\text{दूरबीन}, \text{चोर})$.
3. The transition and emission graph reinforces verbal attachment, tagging *दूरबीन से* as `ARGM-INS` modifying the predicate rather than a nominal modifier (`NMOD`).

### 2. Executive Summary & FAANG Resume Pitch

#### The Problem

Pure end-to-end Large Language Models (LLMs) and standard sequence taggers consistently degrade when extracting structured semantic facts from morphologically rich, syntax-flexible, or code-mixed Indian languages (e.g., Hindi, Marathi, Hindi-English). They suffer from:

1. **Hallucinated Arguments:** Misidentifying who did what to whom when syntactic word order is free (scrambling).
2. **Attachment & Scope Ambiguity:** Incorrectly binding prepositional/postpositional phrases to verbs versus nominal heads.
3. **Polysemy Failures:** Missing subtle domain senses of polysemous predicates where contextual embeddings lack explicit ontology grounding.

#### The Technical Solution

You build a **Neuro-Symbolic Semantic Frame Parser**. The system pairs a deep bidirectional recurrent/seq2seq encoder with an explicit symbolic knowledge prior: **IndoWordNet** (IIT Bombay) and **Paninian Karaka/PropBank semantic frames**.

Instead of relying solely on unconstrained neural generation, the model leverages a **Knowledge-Guided Constrained Decoder (Viterbi-CRF with Ontological Masking)**. Candidate predicate senses are disambiguated against IndoWordNet synset hierarchies, and argument spans are constrained by semantic selectional restrictions (e.g., an agent of *khana* [eat] must subsume the semantic class `[Animate]`).

#### The Resume One-Liner (Target: Google / Meta / Amazon / Microsoft)

### 3. System Architecture & Mathematical Formulation

```
[ Input Sentence (Raw / Code-Mixed) ]
                 │
                 ▼
[ Module 2: Morphological Decomposition (FST / Stemming) ]
                 │
                 ▼
[ Module 5: Contextual Sequence Encoder (BiLSTM / Indic-Encoder) ]
         │                               │
         ▼                               ▼
[ Predicate Identification ]   [ Word Sense Disambiguation (WSD) ]
         │                               │
         │                Grounded in ───┴───► [ IndoWordNet Synsets ]
         │                                          │
         ▼                                          ▼
[ Argument Span & Role Candidate Scorer ] ◄─── [ Selectional Restrictions ]
                 │
                 ▼
[ Neuro-Symbolic Constrained Decoder (CRF + Ontology Masking Matrix M) ]
                 │
                 ▼
[ Structured Frame Output: {Predicate, Sense, Arg0 (Agent), Arg1 (Theme), ...} ]

```

#### Step 1: Input Representation & Morphological Scaffolding

Given a sentence $X = (x_1, x_2, \dots, x_N)$ of $N$ tokens:

1. Tokens are decomposed into base stems and inflectional markers (case clitics, postpositions like *ne*, *ko*, *se*) using morphological decomposition.
2. Each token is encoded into a dense vector:

$$e_i = [w(x_i) \,;\, m(x_i) \,;\, p(x_i)]$$



where $w(x_i)$ is a pretrained contextual embedding, $m(x_i)$ is a morphological feature vector, and $p(x_i)$ indicates predicate candidacy.

#### Step 2: Deep Contextual Encoding (Syllabus 5.1 & 5.2)

The token representations are processed through a stacked Bidirectional Long Short-Term Memory (BiLSTM) network to compute time-step hidden states that capture unbounded left-to-right and right-to-left dependencies:


$$\overrightarrow{h_i} = \text{LSTM}_{\text{fwd}}(e_i, \overrightarrow{h}_{i-1})$$

$$\overleftarrow{h_i} = \text{LSTM}_{\text{bwd}}(e_i, \overleftarrow{h}_{i+1})$$

$$h_i = [\overrightarrow{h_i} \,;\, \overleftarrow{h_i}]$$

#### Step 3: WSD Grounded in IndoWordNet (Syllabus 4.1 & 4.2)

For an identified predicate token $x_p$, candidate synsets $S(x_p) = \{s_1, s_2, \dots, s_K\}$ are queried from IndoWordNet. Each synset $s_k$ has a definitional gloss vector $g_k$ derived from its ontological hypernym path and gloss text.
The predicate sense distribution is computed via an attention score:


$$\alpha_k = \frac{\exp(h_p^T W_s g_k)}{\sum_{j=1}^K \exp(h_p^T W_s g_j)}$$

$$\hat{s}_p = \arg\max_{k} (\alpha_k)$$

#### Step 4: Attachment & Role Disambiguation with Ontological Constraints (Syllabus 3.3 & 4.3)

Each candidate argument span $(i, j)$ with representation $r_{ij} = [h_i \,;\, h_j \,;\, (h_i - h_j) \,;\, h_i \odot h_j]$ is scored against possible semantic roles $R = \{\text{ARG0, ARG1, ARG2, ARGM-LOC, ARGM-TMP, \dots}\}$:


$$\Phi(i, j, r) = W_r \cdot \text{GELU}(W_a r_{ij} + W_p h_p)$$

To prevent structural violations (e.g., multiple conflicting `ARG0` assignments, or non-animate entities acting as voluntary agents), an **Ontology Masking Matrix** $M \in \{0, -\infty\}$ is dynamically constructed from IndoWordNet hypernyms:


$$M(r, \text{Entity-Class}(x_i)) = \begin{cases} 0 & \text{if consistent with IndoWordNet constraints} \\ -\infty & \text{if violation} \end{cases}$$

The global score of a sequence of label assignments $\mathbf{y} = (y_1, \dots, y_T)$ is decoded via a constrained Viterbi Search:


$$S(X, \mathbf{y}) = \sum_{t=1}^T \left( A_{y_{t-1}, y_t} + \Phi(t, y_t) + M(y_t, \text{Entity}(t)) \right)$$

### 4. Step-by-Step Implementation Roadmap

#### Step 1: Environment & Corpus Preparation

* **Datasets:**
* **HDTB (Hindi Dependency Treebank):** Contains gold-standard dependency structures and Paninian karaka roles.
* **Universal Propositions (UP_Hindi):** PropBank-aligned semantic role labels for Hindi.
* **IndoWordNet API / Lexical Database:** Distributed by CFILT, IIT Bombay (available in Python via `pyiwn`).


* **Tooling:** PyTorch, Hugging Face Transformers (`indic-bert` or `muril-base-cased` for baseline representations), `pyiwn`, `seqeval`, ONNX Runtime.

#### Step 2: Data Preprocessing Pipeline

1. Extract sentence tokens, lemmas, postpositions, and target predicate indices.
2. Align Universal Dependencies karaka tags into PropBank/SRL format:
* *Karta* $\rightarrow$ `ARG0` (Agent)
* *Karma* $\rightarrow$ `ARG1` (Patient/Theme)
* *Karana* $\rightarrow$ `ARG2` / `ARGM-INS` (Instrument)
* *Adhikarana* $\rightarrow$ `ARGM-LOC` / `ARGM-TMP` (Location/Time)


3. Convert token labels into BIO (Beginning, Inside, Outside) notation for role spans (e.g., `B-ARG0`, `I-ARG0`, `O`).

#### Step 3: Core Neural Engine Implementation

* **Encoder:** 3-layer BiLSTM ($d_{\text{hidden}} = 512$, Dropout = $0.33$) fed by concatenated 768-dim embeddings from `ai4bharat/indic-bert` and 64-dim morphological feature embeddings.
* **Predicate-Argument Scorer:** Multi-Layer Perceptron (MLP) over pairwise span representations and predicate states.
* **Loss Function:** Negative Log-Likelihood over the constrained CRF graph:

$$\mathcal{L}_{\text{CRF}}(\theta) = -\log \frac{\exp(S(X, \mathbf{y}^*))}{\sum_{\mathbf{y}' \in \mathcal{Y}_{\text{valid}}} \exp(S(X, \mathbf{y}'))}$$



combined with auxiliary cross-entropy loss for predicate sense classification:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CRF}} + \lambda \mathcal{L}_{\text{WSD}}$$



#### Step 4: Symbolic Constraint Injection Layer

Implement a custom Python class `IndoWordNetConstraintEngine`:

1. For an identified predicate (e.g., *kholna* [to open]), query `pyiwn.synsets('खोलना')`.
2. Extract argument selectional constraints (e.g., `ARG0`: Human/Agentive entity, `ARG1`: Inanimate physical object/Lock/Door).
3. If the candidate argument token has an IndoWordNet hypernym path containing `abstract_entity` or fails animacy tests for an agentive verb, penalize the emission score before Viterbi decoding with a large negative bias ($-\infty$).

#### Step 5: Optimization & Productionization

1. Export the trained PyTorch graph to **ONNX (Open Neural Network Exchange)**.
2. Apply **Dynamic INT8 Quantization** to the encoder layers to optimize CPU inference speed.
3. Build a high-throughput **FastAPI** backend with endpoints:
* `POST /parse_frame`: Accepts raw text; returns the predicate, sense, arguments, and visual dependency tree.


4. Wrap the demo in a minimal web UI (React or Streamlit) showing ambiguity resolution side-by-side (Vanilla Seq2Seq vs. Knowledge-Constrained Seq2Seq).

### 7. FAANG Interview Defense Guide

When technical interviewers probe this project, use the following first-principles explanations:

#### Q1: "Why use a neuro-symbolic approach with WordNet instead of just prompting GPT-4 or fine-tuning a larger LLM?"

> *"LLMs excel at fluent surface text generation, but they act as soft probabilistic memorizers that frequently fail deterministic structural constraints in low-resource and scrambled languages. In legal, financial, or clinical extraction, an inverted subject-object relation is a catastrophic failure mode. By constraining the search space during Viterbi decoding with verified ontological axioms from IndoWordNet, we guarantee semantic consistency (e.g., an inanimate object cannot be the agent of a volitional verb) while operating at 1/100th the compute budget and latency of a 70B parameter model."*

#### Q2: "Why BiLSTM over pure self-attention (Transformers) for this specific architecture?"

> *"While Transformers excel at capturing broad global context, BiLSTMs exhibit a strong inductive bias for strictly ordered linear sequences and local syntactic compositionality. In morphologically rich languages where local case markers (clitics) immediately dictate the semantic role of an entire preceding noun phrase, recurrent hidden state transitions ($\overrightarrow{h_t}, \overleftarrow{h_t}$) maintain tight locality sensitivity without suffering from quadratic attention overhead on variable-length texts."*

#### Q3: "How does your system resolve Prepositional/Postpositional Attachment Ambiguity mathematically?"

> *"Attachment ambiguity occurs when a modifier (e.g., 'with a telescope') can bind to either a verbal head (instrument) or a nominal head (attribute). We formulate this as an edge scoring problem: we compute the bilinear affinity tensor between the modifier representation $h_m$ and the two candidate heads $h_v$ and $h_n$. We then intersect this score with the predicate's semantic frame in IndoWordNet. If the predicate sense explicitly admits an instrumental role (`ARGM-INS`), the constraint matrix increases the prior probability of the verb attachment edge."*
